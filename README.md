# Flight Ops — a 2D air combat game on real-world maps

### Link: https://dor-yeheskel.itch.io/flight-ops

### Demo: https://www.youtube.com/watch?v=mLi7nS4pmlM

## 🧭 Overview

✈️ 2D air combat over real-world terrain  
🌍 Cities, coasts, deserts, mountains — actual map data  
📡 Radars, missiles, targets. No scripted paths.  

ℹ️ For best visuals, make sure your browser zoom is set to 100%.

## 🎮 Controls

⬆️ ⬇️ — Speed  
⬅️ ➡️ — Turn  
Space — Drop bomb 💣  
Shift — Stealth 🕶️

## 🎯 Mission objective
Destroy all targets in the level.

## ⭐ Scoring Rules

✔️ Destroy every target  
✔️ Use the minimum possible bombs  
✔️ Never use stealth  

Anything less = lower score.

🥇 Gold — near-perfect execution
🥈 Silver — solid run
🥉 Bronze — mission completed

## ⚡ Game Feel
Fast. Reactive. Unforgiving.  
Bombing is easy. Precision is not.
